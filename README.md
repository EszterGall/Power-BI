Power BI Business Dashboard


A team project created at Business IT Club Corvinus. Took business data (from a fictional company), cleaned it up, and turned it into an interactive Power BI dashboard for quick operational and performance tracking.

What We Built
Data Prep: Cleaned raw records, handled missing values, and standardized formats for consistent reporting.

Visuals & Charts: Built clear bar charts, trend lines, and KPI cards to highlight key business metrics without visual clutter.

Interactive Dashboard: Set up slicers and cross-filtering to let users explore segments, timeframes, and outliers easily.

Tech Stack
Tool: Microsoft Power BI Desktop

Source: Raw Excel / CSV datasets

How to View:
Download the .pbix file.
Open it in Power BI Desktop.
Use the filters and charts to explore the data.
